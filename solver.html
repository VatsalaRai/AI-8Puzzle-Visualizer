        PSEUDOCODE

        function UCS(start, goal):
  open   = min-heap ordered by g(n)
  open.push(start, g = 0)
  closed = empty set

  while open is not empty:
    node = open.pop()          # cheapest g first
    if node.state in closed: continue
    if node.state == goal:     # goal test on selection
      return path(node)
    closed.add(node.state)

    for each legal move (up, down, left, right):
      child   = apply(move, node)
      g_child = g(node) + stepCost(move)
      if child.state in closed: skip
      if child.state in open with g <= g_child: skip
      open.push(child, g_child)   # replaces a costlier copy

  return FAILURE

        READING THE PANELS

        • Current node: the node just taken off the open list, with its parent, depth and path cost g(n). UCS has no heuristic, so h(n) = 0 and f(n) = g(n).
        • Successors: up to four boards made by moving the blank. Each one is added, replaces a costlier copy, or is skipped.
        • Open list: the frontier. It is a priority queue, so the lowest g is always expanded first.
        • Closed list: states already expanded. They are never expanded twice.
        • Step slider: drag to jump to any step of the search and replay it from there.
